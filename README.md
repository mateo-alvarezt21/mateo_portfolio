# Mateo - Portafolio Personal

**¡Bienvenido a mi portafolio!**

Soy Mateo, un desarrollador apasionado por el desarrollo web. Este portafolio muestra una colección de mis proyectos más recientes, construidos principalmente con React.

### Sobre mí
* **Resumen:** Soy un desarrollador web con una fuerte pasión por crear aplicaciones modernas y eficientes. Con experiencia en desarrollo frontend y backend, me especializo en construir interfaces de usuario intuitivas y soluciones escalables. Estoy motivado por el aprendizaje continuo y me encanta enfrentar nuevos desafíos tecnológicos.
* **Tecnologías:**  React, JavaScript, HTML, CSS, Node.js, Express, MongoDB, Next.js, Tailwind CSS

### Cómo ejecutar el proyecto localmente
1. **Clonar el repositorio:**
   ```bash
   git clone
   ```
2. **Instala las dependencias necesarias:**
   ```bash
   npm install
   ```
3. **Compilar y montar el proyecto:**
   ```bash
   npm run dev
   ```
